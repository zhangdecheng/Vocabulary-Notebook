# 单词故事 + Anki 单词卡 制作 Prompt（可直接交给其他 agent）

> 用法：把「通用背景」+ 需要的那一份 Prompt 一起发给 agent，并附上最新的《单词总表》CSV。

---

## 0. 通用背景（两份 Prompt 都要带上）

- 学习者：中文母语，英语 B1，目标 B2 职场英语；住在印尼巴厘岛；希望表达地道、准确。常犯错误：时态、第三人称 -s、冠词、拼写。
- 输入：《单词总表》CSV，列为 `#,单词,音标,中文,主题,高频,出现次数,出现日期,来源,笔记线索`。
  - `主题` 用来分章（如「① 性格与情绪」）；`高频` 为 ★ 表示重点词；音标为空要自己补全（准确的 IPA）。
  - 如有旧版词表，先做 diff，标出新增词（NEW）。
- 发音：用 edge-tts 神经语音生成真人感音频，美式 `en-US-AvaNeural`，英式 `en-GB-SoniaNeural`。全部为 AI 生成，需在页面注明。
- 质量要求：不编造释义；例句地道、符合 A2–B1；完成后用无头 Chrome 实测（无控制台报错、弹窗/音频/测验可用、手机视口正常），并截图留证。
- 部署：做成纯静态网站（相对路径），可放 GitHub Pages / Cloudflare Pages / 自有服务器 nginx。当前线上地址 https://v.zdc.sh.cn （服务器发布由工程负责人用 rsync 同步 site/ 目录）。另出「单文件版」HTML 便于离线打开，单个文件需 < 24 MB（聊天附件上限 25 MB），超了按章节拆分。

## Prompt A：单词故事（中英对照 HTML）

请根据附件《单词总表》写一套连贯的中英对照英文故事，并输出为美化过的 HTML，帮助我在语境中理解和记忆单词。

**故事要求**
1. 覆盖词表里的**全部单词**，每个词至少出现一次，★ 高频词尽量出现 2 次以上；完成后输出覆盖率检查（应为 100%）。
2. 按「主题」分章，一个主题一章，词多的主题可拆成多章。
3. 固定角色与场景：Leo、Sonia、Kenji、Ana、Pak Made、Ketut，故事发生在巴厘岛，贴近日常生活与工作（办公室、会议、邮件、客户、租房、出行等）。
4. 英文整体控制在 **A2–B1**：短句、简单结构、常用词；只有词表里的单词加粗高亮，其它词不要加粗。
5. 每个目标词都要用在**能看出意思**的自然语境里，不要生硬堆砌。
6. 每段英文配对应中文翻译。

**页面功能**
- 点击高亮单词弹出卡片：中文释义、音标、🇺🇸 美式 / 🇬🇧 英式两个发音按钮、★ 高频与 NEW 标记、常用搭配（collocations），以及 **2–3 个拓展应用场景**（💼 工作 / 🏠 日常 / 🌴 巴厘岛生活），每个场景一句 A2–B1 英文例句 + 中文 + 🔊 发音。
- 中英对照 / 只看英文 / 只看中文 切换；页面级美式/英式口音切换。
- 段落朗读（神经语音），朗读时逐词高亮同步。
- 每章末尾：本章单词表（每个词都有美式、英式两个发音按钮，可勾「已掌握」）+ 上一章 / 下一章导航。**不要**加填空小测，也不要在章节里或章节列表末尾加「说明」区块（10/24 用户反馈多余，已去掉）。
- 搜索、自测模式（隐藏释义）、移动端友好、美观排版。

**输出**
- 静态网站：`index.html`（入口）、`stories.html`、`data/words.json`（+ 同内容的 `words.js` 便于 file:// 打开）、`audio/us/`、`audio/uk/` 下单独的 MP3。
- 单文件版：美式、英式各一份（音频 base64 内嵌、懒加载解码），超过 24 MB 按章节拆成 Part1/Part2。
- 汇报：文件路径与大小、章节数、新增词数、覆盖率、注意事项。

## Prompt B：Anki 单词卡（间隔复习 HTML）

请用附件《单词总表》和已经写好的单词故事，做一个 Anki 风格的在线间隔复习页面。卡片里的例句要围绕我故事里的场景。

**卡片内容**
- 正面：单词；可选显示故事原句并把该词挖空（cloze）。支持反向模式：看中文说英文。
- 背面：音标、中文、🇺🇸/🇬🇧 发音按钮、**故事中的原句**（注明第几章，并可跳回故事页对应位置）、常用搭配、拓展场景例句（工作 / 生活·巴厘岛，含中文和发音）、词表里的「笔记线索」。

**复习逻辑**
- SM-2 风格算法：重来 / 难 / 记得 / 简单 四档；学习阶段步长 1 分钟、10 分钟。
- 每日新卡上限可设置（默认 20，非法值或 0 自动重置为 20）；显示 新 / 学习中 / 待复习 数量。
- 按主题、★ 高频、NEW 筛选；筛选结果为空时显示提示和「清除筛选」按钮；当天学完显示「再学 20 张新卡」。
- 快捷键：空格翻面，1–4 打分，U/K 切换美式/英式发音，Z 撤销。
- 进度存在 localStorage，支持 JSON 导出/导入备份；**localStorage 不可用时自动退回内存模式**并提示导出。
- 健壮性：任何脚本错误都要在页面显示 ⚠️ 提示而不是空白；单词数据没加载到时给出明确说明（例如 data/ 没上传、或在聊天预览里打开）。打开页面无需任何设置就能直接看到第一张卡。
- 手机端友好。

**输出**
- 网站版 `anki.html`，与故事网站共用 `data/` 和 `audio/`。
- 单文件版 `单词卡_Anki.html`（< 24 MB，内嵌美式+英式单词音频，先渲染卡片再加载音频）。
- 测试：桌面 + 手机视口 + 禁用 localStorage + 空筛选 + 数据缺失，各截一张图。

## 更新流程（新词表进来时）
1. 和旧词表 diff，列出新增 / 删除 / 改动的词。
2. 旧章节保留并重新映射编号；只为新增词写新章节或补进相关章节。
3. 未改动的段落和单词复用已有音频，只为新内容生成新音频。
4. 重新生成网站和单文件版，跑完整测试。
5. 把 site/ 交给工程负责人同步上线，并核查线上 data/ 和 audio/ 返回 200。
